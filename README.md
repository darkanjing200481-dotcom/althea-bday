# Althea Birthday Website 🌷

A beginner-friendly birthday website made with plain HTML, CSS and JavaScript.

## Project structure

- `index.html` — page content
- `style.css` — pastel/crochet-inspired design
- `script.js` — buttons, scroll reveals and envelope surprise
- `assets/photos/` — your uploaded photos
- `assets/videos/` — your uploaded goofy clips

## Run locally

Open `index.html` in your browser.

For a better local preview in VS Code, use the **Live Server** extension.

## Deploy to Vercel

1. Create a GitHub repository.
2. Upload all files/folders from this project.
3. Go to Vercel and import the GitHub repository.
4. Framework preset: **Other**.
5. Deploy.

No build command is needed.

## Before sending the link

- Test on your phone.
- Check both videos load.
- Replace/edit any captions you want.
- Decide whether you want the letter text to stay as-is or make it more personal.
